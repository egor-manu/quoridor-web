1. Incumbent diagnosis

The browser’s current Hard search was run five times from the same standard 9×9 position after Player 1’s opening pawn move. Every run selected pawn → row 2, column 5. It completed depth 3 in roughly 902–911 ms (mean ≈907 ms), visiting 1,344–1,440 nodes.

The result follows directly from the implementation: Hard has zero noise, zero mistake probability, deterministic candidate ordering, a 900 ms budget, and at most 16 wall candidates. Replaying a position therefore replays the same principal variation.

4. Why high accuracy did not become strong play

  1. Outcome prediction is not policy improvement. The network learned correlations in shallow self-play but did not learn which counterfactual move changes the result.
  2. The corpus was small and correlated. A random position split allows positions from the same game into train and validation sets, inflating the apparent 88.8% accuracy.
  3. Exploration collapsed. The learned values produced one dominant opening, so root temperature could not create meaningful variety.
  4. CPU rules dominated runtime. CUDA training was fast; repeated pathfinding and legal-wall enumeration consumed most of the 239 seconds.
  5. The opponent in the 10-game match was a faithful deterministic Python proxy, not the time-budgeted TypeScript binary. These results reject the candidate, but must not be presented as a calibrated rating against the deployed Hard AI.

5. Recommended next experiment

Use a small AlphaZero-style policy + value residual network with PUCT, trained from visit-count targets rather than final outcomes alone. Canonical board planes should encode pawns, horizontal walls, vertical walls, remaining walls, and side to move. Export weights to ONNX or a compact typed-array format for Web Worker inference.

Before scaling self-play, replace repeated wall scans with bit-mask edge occupancy, cached legal transitions, and game-level train/validation splits. Add controlled root Dirichlet noise during training and sample only within a narrow visit-count band during play; forced wins and clearly superior moves remain deterministic.
